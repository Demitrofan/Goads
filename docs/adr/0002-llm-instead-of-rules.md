# ADR-0002. Разбор объявлений LLM вместо ручных правил

- **Статус:** принято
- **Дата:** 2026-10-14

## Контекст

- Объявления написаны в свободной форме: смесь русского и английского, сленг и сокращения
  («2бхк», «кондей», «45к», «овнеры рядом»), цены по сезонам, комиссия то в процентах, то суммой.
- Первая версия проекта (2024) обращалась к GPT через бесплатные неофициальные обёртки (g4f и подобные) —
  они регулярно ломались. Затем разбор шёл ручными правилами в отдельных скриптах по разделам:
  каждый новый вариант написания требовал нового правила.
- Нужно отличать объявления от болтовни, поисков, рекламы, обмена валют — правилами это почти не решается.
- Бюджет — единицы долларов в месяц; объём на момент решения — около 3 000 сообщений в неделю (только Гоа),
  сейчас — около 8 000 (4 региона, 55 каналов).

## Варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Ручные правила и регулярные выражения | Бесплатно, предсказуемо | Не покрывают свободный текст; дорого сопровождать; не определяют вид объявления |
| Бесплатные неофициальные обёртки GPT | Бесплатно | Нестабильны, могут перестать работать в любой день; нет гарантий и JSON-режима |
| Своя обученная модель | Нет платы за запросы | Нужна размеченная выборка и опыт ML; несоразмерно задаче |
| **LLM через API (OpenRouter)** | Понимает сленг и смесь языков; один промпт на все разделы; модель меняется настройкой | Плата за запросы; ответ недетерминирован; зависимость от внешнего сервиса |

## Решение

Разбирать каждое сообщение LLM через OpenRouter (API, совместимый с OpenAI) с ответом в JSON.

**Выбор модели — на эталонном наборе:** 12 сообщений с заранее известным правильным разбором.
`qwen/qwen3.7-flash` — 11 из 12 верно, `deepseek-v4-flash` — 10 из 12. Выбрана `qwen3.7-flash`.

**Меры против недостатков LLM:**

| Риск | Мера |
|---|---|
| Стоимость | Точные дубли отсекаются по хэшу до LLM; сообщения старше срока актуальности (7 / 14 дней) не разбираются; текст обрезается до 4 000 символов; месячный лимит $5 на ключе и тревога при остатке < $1 |
| Недетерминированность | `temperature = 0`, JSON-режим, подробный промпт с допустимыми значениями и примером |
| Неверные типы и значения | Каждый ответ приводится к схеме (`_clean`): числа, списки допустимых значений, диапазон года |
| Логические ошибки разбора | Бизнес-правила после LLM: обязательная цена, порог дешёвого жилья ([ADR-0004](0004-cheap-rent-to-trash.md)), отсев рекламы проката с ценой «от X», справочники районов и моделей байков поправляют ответ |
| Сбои сервиса | 3 попытки с паузой; при неудаче — статус `error` и повтор в следующем цикле |
| Привязка к поставщику | Модель и адрес API — настройки `LLM_MODEL`, `LLM_BASE_URL` |

## Последствия

- ➕ Неделя сообщений Гоа (~3 000) разобрана за **$0.32** — около $0,0001 за сообщение.
  С четырьмя регионами (подсказки длиннее) — ~$0,0002 за сообщение, **$1,78 за октябрь**, ~$4–5 в месяц
  при текущем объёме ([цифры](../06-metrics.md)).
- ➕ Один сервис для трёх разделов: LLM сам определяет вид объявления, каналы можно не делить по темам.
- ➕ Новая страна — новая подсказка, а не новый парсер: LLM сразу переводит районы, валюты и способ счёта комнат
  ([ADR-0005](0005-regions-as-config.md)).
- ➕ Прайс-листы разбираются в список позиций — отдельные карточки для каждой.
- ➖ Ошибки разбора возможны (1 из 12 на эталоне) и не всегда видны — нужен выборочный контроль.
- ➖ Без денег на счёте OpenRouter разбор останавливается (сообщения ждут в статусе `new`).

## Когда пересмотреть

- Появится заметно более дешёвая или точная модель — прогнать эталон и сменить `LLM_MODEL`.
- Эталон из 12 сообщений мал: при росте числа ошибок расширить его и сделать регулярной проверкой.
