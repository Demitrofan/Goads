# ADR-0003. Отдельный VPS для сайта вместо существующего сервера

- **Статус:** принято
- **Дата:** 2026-10-16

## Контекст

- У владельца уже был сервер с другими рабочими процессами, для которых важна непрерывная работа.
  Памяти на нём почти не оставалось (около 1,4 ГБ всего), уже случались аварийные остановки процессов
  из-за нехватки памяти (OOM).
- Сайту нужны nginx, Gunicorn с несколькими воркерами и служба сбора, которая при разборе держит
  в памяти пачки ответов LLM и обрабатывает фото.
- Telegram-сессия должна работать только в одном месте: одновременное использование одной сессии
  с двух машин ломает соединение.

## Варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Существующий сервер | Бесплатно, уже настроен доступ | Сайт может вытеснить критичные процессы из памяти; любой сбой сайта — риск для них |
| Сбор на домашнем компьютере, сайт на сервере | Нагрузка разбора не на сервере | Компьютер должен быть всегда включён; нужно синхронизировать базу и фото |
| **Отдельный VPS** | Полная изоляция; можно свободно настраивать и перезапускать | ~$5 в месяц |

## Решение

Арендовать отдельный VPS (2 ГБ памяти, ~$5 в месяц) только под Goads: nginx, Gunicorn, служба сбора,
SQLite и фото на одной машине. Сбор перенесён на сервер вместе с Telegram-сессией; локальный запуск
сбора отключён, чтобы сессия не использовалась в двух местах.

## Последствия

- ➕ Сбои и нагрузка сайта не затрагивают другие процессы владельца.
- ➕ Сайт и сбор работают круглосуточно, без домашнего компьютера.
- ➕ Для службы сбора задан лимит памяти, чтобы она не вытеснила сайт.
- ➖ Дополнительный расход ~$5 в месяц и ещё один сервер в обслуживании (обновления, сертификат HTTPS —
  продлевается автоматически).
- ➖ Локальная разработка идёт без живого сбора: тестировать сбор локально с рабочей сессией нельзя.

## Когда пересмотреть

- Нехватка памяти или диска (фото копятся) — увеличить тариф или чистить старые фото.
- Мультирегиональность — несколько служб сбора могут потребовать больше ресурсов.
