# ADR-0005. Новые страны — настройкой в той же системе, а не отдельной копией сайта

- **Статус:** принято
- **Дата:** 2026-10-17

## Контекст

- У русскоязычных в Армении, Грузии, на Пхукете те же проблемы, что в Гоа: объявления о жилье
  разбросаны по Telegram-каналам в свободной форме.
- Хотелось быстро проверить спрос (MVP), не удваивая сервера, расходы и сопровождение.
- Отличия регионов: свои каналы, районы и города, валюта цены, как считают комнаты
  («2-комнатная» в Ереване ≠ «2BHK» в Гоа), срок жизни объявления, набор разделов.

## Варианты

| Вариант | Плюсы | Минусы |
|---|---|---|
| Отдельная копия сайта и сборщика на страну | Полная независимость | Каждая правка — в N местах; N серверов, N Telegram-сессий и баз |
| Отдельная база на страну в одном сайте | Данные не смешиваются | Маршрутизация баз, миграции N раз; общий отчёт и бот сложнее |
| **Поле `region` в общей модели + таблица настроек регионов** | Один сборщик, одна сессия, одна база; новый регион — несколько записей | Код должен везде помнить о регионе; ошибка в фильтре может «перемешать» страны |

## Решение

- У `Listing` и `MotoListing` поле `region` (`goa`, `am`, `ge`, `th`); у жилья вне Гоа — ещё `city`.
- **Сборщик** (`EXTRA_REGIONS` в `services/ads/service.py`): регион → файл каналов, своя подсказка GPT,
  разрешённые разделы. Регион сообщения определяется по каналу.
- **Подсказка GPT на регион** возвращает цену в валюте объявления (`currency`); сборщик переводит её в рупии
  (`price_to_rupees`) — в базе по-прежнему одна валюта.
- **Сайт**: `REGIONS` и `HOME_CARDS` в `ads/views.py`, `REGIONS` в `moto/views.py`, `REGION_SEO`, `REGION_PREFIXES`,
  адреса `/am/`, `/ge/`, `/th/`. Комнаты, районы, период по умолчанию, валюты — из настроек региона.
- Раздел, которого в регионе нет (барахолка в Армении), не создаётся: сообщение уходит в мусор с причиной `<регион>_<вид>`.

## Последствия

- ➕ Армения, Грузия и Пхукет запущены за три дня; расходы выросли только на разбор GPT.
- ➕ Бот уведомлений, сводка владельцу, проверка «снято», резервные копии сразу работают для всех стран.
- ➕ По тем же правилам считаются метрики: можно сравнивать регионы ([цифры](../06-metrics.md)).
- ➖ Регион нужно не забывать в каждом запросе: детальная страница объявления чужого региона перенаправляет на «свой» адрес.
- ➖ Подсказки GPT по регионам длиннее — разбор подорожал примерно с $0,0001 до $0,0002 за сообщение.
- ➖ По-прежнему один процесс пишет в SQLite — рост числа стран упирается в длительность одного цикла.

## Когда пересмотреть

- Цикл сбора перестанет укладываться в 10 минут — делить сборщик по регионам (и, вероятно, перейти на PostgreSQL).
- Регионы начнут сильно расходиться по полям (свои фильтры удобств на страну — в планах).
