## Деньги

| Статья | Сумма | Комментарий |
|---|---|---|
| Разбор GPT (`qwen/qwen3.7-flash` через OpenRouter) | **$1,78 за октябрь** (~8 600 сообщений) | ≈ $0,0002 за сообщение |
| Разбор GPT при текущем объёме (55 каналов) | ~$4–5 в месяц | Ключ с лимитом $5 в месяц, тревога при остатке < $1 |
| VPS (2 ГБ RAM, 29 ГБ диск, Франкфурт) | $5 в месяц | Занято ~620 МБ памяти и 5,4 ГБ диска |
| Резервные копии, мониторинг, HTTPS | $0 | systemd-таймеры, Telegram-бот, Let's Encrypt |
| **Итого** | **≈ $10 в месяц** | без домена |

Как держится цена:

- точные дубли (треть потока) узнаются по хэшу текста и в LLM не идут;
- сообщения старше срока актуальности не разбираются;
- текст обрезается до 4 000 символов, `temperature = 0`, ответ — компактный JSON;
- модель выбрана на эталонном наборе: `qwen3.7-flash` — 11 из 12 верно, `deepseek-v4-flash` — 10 из 12
  ([ADR-0002](adr/0002-llm-instead-of-rules.md)).

На старте (только Гоа, 34 канала) неделя сообщений (~3 000) разбиралась за $0,32 — ~$0,0001 за сообщение.
С новыми регионами подсказки GPT длиннее (районы, валюты), отсюда ~$0,0002.

## Работа системы

| Показатель | Значение |
|---|---|
| Цикл сбора | каждые 10 минут; новое объявление на сайте в пределах цикла |
| Параллельных запросов к LLM | 8 |
| Проверка «снято» | раз в 18 циклов (~3 часа), объявления за 30 дней |
| Догрузка истории новых каналов | 100 сообщений с канала за цикл, до 14 дней назад |
| Сторож | каждые 10 минут: служба жива, цикл был < 40 минут назад, на GPT ≥ $1 |
| Сводка владельцу | каждое утро в 9:00 по Гоа, в Telegram |
| Резервные копии базы | каждую ночь на сервере (хранятся 7) + раз в неделю на домашний компьютер (8) |
| Объём кода | ~3 900 строк Python, шаблоны и JS без фреймворков |

## Пользователи

Сайт для «своих» — расчёт на десятки человек, без рекламы и монетизации. На момент среза он в тестировании
и публично не анонсирован: посетителей — единицы в сутки, у бота уведомлений один подписчик (владелец).
Посетители считаются по журналу nginx без cookie-счётчиков; есть Яндекс Метрика.
