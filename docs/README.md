# Документация системного аналитика — Goads

Набор артефактов по проекту Goads: агрегатор объявлений из Telegram для русскоязычных в Гоа (Индия),
Армении, Грузии и на Пхукете (Таиланд) — [goadoska.ru](https://goadoska.ru).
Всё описано по фактическому коду репозитория и рабочей базе; у каждого документа указаны файлы-источники.
Состояние — на 19.10.2026. Диаграммы — Mermaid, GitHub рисует их прямо на странице.

## Коротко о проекте

| | |
|---|---|
| Регионы | Гоа (жильё, байки, барахолка), Армения и Грузия (жильё), Пхукет (жильё, байки) |
| Источники | 55 открытых Telegram-каналов и групп (Гоа 34, Армения 7, Грузия 5, Пхукет 9) |
| Поток | ~1 150 сообщений в сутки → ~210 новых объявлений в сутки |
| Актуальных объявлений | ~3 100 |
| Разбор | LLM `qwen3.7-flash` через OpenRouter, ≈ $0,0002 за сообщение, ~$4–5 в месяц |
| Инфраструктура | Один VPS за $5 в месяц: nginx, Gunicorn, служба сбора, SQLite, systemd-таймеры |
| Сопровождение | Сторож, тревоги и утренняя сводка в Telegram, ночные резервные копии |

## Словарь

| Термин | Значение |
|---|---|
| Сообщение (`Post`) | Сырой текст из Telegram-канала (альбом из нескольких фото — одно сообщение) |
| Объявление, карточка | Результат разбора: `Listing` (жильё), `MotoListing` (байк), `StuffListing` (вещь) |
| Раздел, вид | `rent` — жильё, `bike` — байки, `sale` — барахолка |
| Регион | `goa` — Гоа, `am` — Армения, `ge` — Грузия, `th` — Пхукет; определяется по каналу-источнику |
| Подсказка (промпт) региона | Инструкция для LLM со своими районами, валютами и способом счёта комнат |
| Точный дубль | Сообщение, чей нормализованный текст (без ссылок, @ников, телефонов, знаков) совпал с уже обработанным |
| Склейка | Привязка нового сообщения к существующему *похожему* объявлению (не точный дубль) |
| Мусор | Сообщение, которое не стало объявлением; причина — в `Post.trash_reason` |
| Срок актуальности | Сообщения старше него не разбираются: Гоа — 7 дней, остальные регионы — 14 |
| Догрузка истории | Чтение каналов новых регионов назад, до 14 дней, по 100 сообщений за цикл |
| Прайс-лист | Сообщение с несколькими объектами и своими ценами (`many_objects`) → несколько карточек |
| Снято | Объявление сдано, продано или удалено автором (`closed`); из списков пропадает |
| Код модели (`family`) | Модель байка по справочнику: «Yamaha Aerox 155» и «aerox» — один код `aerox` |
| Подписка | Сохранённый фильтр поиска; бот присылает новые объявления под него |
| Сторож, сводка | Проверка каждые 10 минут и утренний отчёт владельцу в Telegram |
| LLM | Языковая модель, разбирающая текст в JSON (через OpenRouter) |
| ₹ | Индийская рупия; все цены в базе хранятся в рупиях, показываются в выбранной валюте |
